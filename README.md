## Job Application Tracker

A console-based Java application for managing and tracking job applications through different recruitment stages.

## Features

* Add job applications
* View all applications
* Search applications by company
* Update application status
* Delete applications
* Filter applications by status

## Application Information

Each application contains:

* Application ID
* Company Name
* Job Role
* Application Date
* Application Status

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

* Classes and Objects
* Constructors

## Application Statuses

* Applied
* Online Assessment
* Interview
* Selected
* Rejected

## How to Run

1. Open the project in IntelliJ IDEA.
2. Compile the Java files.
3. Run `JobApplicationTracker.java`.
4. Select an option from the menu.
5. Follow the instructions displayed in the console.

## Data Storage

The current version stores application data in memory using `ArrayList`. Data is cleared when the application is closed.
